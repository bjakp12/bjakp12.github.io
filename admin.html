How to publish (GitHub Pages)

  1. Click Save & Preview to see changes instantly on index.html (this browser only).
  2. Click Export projects.json, then replace the repo's projects.json with the downloaded file.
  3. Commit & push: git add projects.json && git commit -m "Update projects" && git push. GitHub Pages redeploys automatically.
  4. Recommended: do NOT deploy admin.html publicly. Keep it local, or rename it to something unguessable (e.g. manage-x7q2.html) and never link it from the site.
  5. If you must host it: set a 12+ character password, and clear “Save & Preview” plaintext data on shared computers via Reset → logout.
