Firebase is not connected yet

  1. Create a free project at console.firebase.google.com.
  2. Left menu → Build → Firestore Database → Create database (production mode, any region).
  3. Left menu → Build → Authentication → Get started → enable Email/Password → add a user (your admin email + strong password).
  4. Project Overview (gear icon) → Project settings → Your apps → Web app → copy the firebaseConfig values.
  5. Copy firebase-config.example.js to firebase-config.js, paste your values, and deploy it together with this file.
  6. In Authentication → Settings → Authorized domains, add bjakp12.github.io.
  7. Publish the rules in firestore.rules (Firestore → Rules tab → paste → Publish).

How this works

  1. Everything you save here goes straight into Firestore — the live database.
  2. The public site listens to the database in real time: edits appear within seconds, no rebuild, no re-export.
  3. Writes require login (enforced by firestore.rules on Google's servers — not just in this page).
  4. Images: put files in the repo's images/ folder and push, then reference them (e.g. images/shot.jpg) — or paste any https:// image URL.
